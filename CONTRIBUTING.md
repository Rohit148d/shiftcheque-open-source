# Contributing to ShiftCheque

Useful issues and pull requests are welcome, especially around accessibility,
security, accurate payroll rules, tests, and Canadian French localization.

1. Open an issue before large or breaking changes.
2. Cite official government sources for rule changes, including the
   jurisdiction, effective date, examples, and rounding assumptions.
3. Include synthetic test cases; never include personal wages, shift schedules,
   payslips, bank information, keys, tokens, or production data.
4. Run `npm ci` and `npm run verify` locally.
5. Describe your changes and link relevant issues in your pull request.
6. Ensure you have permission to redistribute any third-party assets.

Please do not inflate stars, downloads, issues or contribution counts to seek
developer-program benefits. Contributions should provide real value.

See SECURITY.md for private vulnerability reports.
